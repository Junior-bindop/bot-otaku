# 📁 Dossier des Stickers

Place ici tous les stickers au format `.webp` utilisés par le bot.

## Liste des stickers attendus

| Nom du fichier          | Utilisé quand...                                          |
|-------------------------|-----------------------------------------------------------|
| `welcome.webp`          | Un nouveau membre rejoint le groupe                       |
| `bot_mention.webp`      | Quelqu'un mentionne le bot avec @                         |
| `greeting.webp`         | Quelqu'un dit bonjour/salut/hello/bonsoir                 |
| `middle_finger.webp`    | Quelqu'un envoie l'emoji 🖕                               |
| `poll.webp`             | Quelqu'un envoie un sondage                               |
| `special_member.webp`   | Le membre spécial est mentionné                           |
| `quiz_first_correct.webp` | Premier à trouver la bonne réponse à une question       |
| `quiz_first_wrong.webp` | Premier à répondre mais avec une mauvaise réponse         |
| `quiz_too_late.webp`    | Bonne réponse mais après la fin du temps imparti          |

## Comment convertir un sticker WhatsApp en .webp ?

1. Transfère le sticker depuis WhatsApp vers ton PC (via partage par mail ou autre).
2. Il arrivera déjà en format `.webp`.
3. Renomme-le selon le tableau ci-dessus et place-le dans ce dossier.

> ⚠️ Si un fichier est absent, le bot enverra juste le texte sans sticker — il ne plantera pas.
